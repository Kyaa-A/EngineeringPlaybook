# Release Checklist

## Product

- [ ] Acceptance criteria pass.
- [ ] User-visible error and degraded states work.

## Engineering

- [ ] Typecheck, lint, tests, and build pass.
- [ ] Migrations are reviewed and production-like tested.
- [ ] Security and dependency checks pass.
- [ ] Performance budgets are met.

## Operations

- [ ] Configuration and secrets are validated.
- [ ] Dashboards and alerts are ready.
- [ ] Backups and restore are verified.
- [ ] Rollback or kill switch works.
- [ ] Smoke test and canary owner are assigned.
