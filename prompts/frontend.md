# Frontend Prompts

## Experience design

```text
Design the frontend for {{workflow}}. Define routes, information hierarchy, component boundaries, server/client rendering, state ownership, API contracts, and loading, empty, success, partial, validation, denied, offline, timeout, and unexpected-error states. Include accessibility, responsive behavior, analytics, performance budgets, and end-to-end acceptance cases.
```

## Performance review

```text
Review this frontend using measured evidence. Separate verified bottlenecks from hypotheses. Inspect client boundaries, bundle size, dynamic loading, images, fonts, duplicate requests, caching, payloads, third-party scripts, LCP, INP, CLS, and API p95. Give a measurement and expected impact for every recommendation.
```
