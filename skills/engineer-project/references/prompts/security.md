# Security Prompts

## Threat model

```text
Threat-model {{system}}. Cover authentication, authorization, tenant isolation, secrets, data retention, injection, unsafe output handling, CSRF, CORS, CSP, abuse, file uploads, webhooks, dependencies, prompt injection, retrieval poisoning, excessive tool permissions, sensitive logging, and denial-of-wallet. For each credible threat give prerequisites, attack path, impact, controls, missing controls, and a safe test.
```
